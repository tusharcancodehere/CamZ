# Support Guide

If you run into issues or have questions regarding CAMZ setup or configuration, please refer to the resources below.

## 🔍 Troubleshooting

1. **Verify Capabilities**:
   Always run diagnostics first to identify if your platform supports the requirements:
   ```bash
   python scripts/detect_platform.py
   ```
2. **Read System Logs**:
   Logs are recorded to `logs/camera.log`. View them live inside the app under the **System Logs** page or via terminal:
   ```bash
   tail -n 50 logs/camera.log
   ```

## 💬 Community Channels

- **GitHub Issues**: Open a bug report or search for similar problems in existing issues.
- **Discussions**: Share configurations, request templates, or showcase your Raspberry Pi camera setups.
