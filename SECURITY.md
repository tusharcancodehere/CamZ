# Security Policy

## Supported Versions

Only the latest release (normally master/main branch) is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in CAMZ, please do not disclose it publicly. Report it directly by opening a private report or sending details to **security@camz-project.org**.

We will evaluate the issue and draft a patch within 48 hours.
